# CRM Lead Card

Тестовый frontend-модуль для добавления лидов в мини-CRM, локального хранения данных и изменения этапа сделки. Backend и внешние сервисы не используются.

## Стек

- HTML5;
- CSS3;
- JavaScript;
- `localStorage`.

## Реализованный функционал

- форма с именем клиента, телефоном, источником лида, ответственным и этапом сделки;
- переключатель «Запрошено ТЗ»;
- валидация обязательных полей имени и телефона;
- создание и отображение карточек лидов;
- сохранение и восстановление лидов через `localStorage`;
- изменение этапа сделки с сохранением нового значения;
- адаптивный интерфейс для ноутбука и телефона.

## Как запустить

Откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```

Приложение также можно открыть напрямую через `index.html`, но локальный сервер удобнее для разработки и проверки.

## Хранение данных

Данные сохраняются в `localStorage` текущего браузера под ключом `crm_leads`. Это тестовый frontend-модуль без backend, поэтому данные не синхронизируются между браузерами или устройствами и могут быть удалены при очистке данных сайта.

## Структура проекта

- `index.html` — интерфейс формы и раздел «Сохранённые лиды».
- `styles.css` — нейтральное оформление CRM и адаптация для ноутбука и телефона.
- `script.js` — валидация, создание и отображение лидов, работа с `localStorage`.
- `README.md` — инструкция по запуску и проверке.

## Где находится основная логика

- HTML-интерфейс: `index.html`, форма `#leadForm` и список `#leadsList`.
- Обработчик кнопки сохранения: обработчик события `submit` в конце `script.js`.
- Валидация: функции `validateForm()`, `setFieldError()` и `clearFieldError()`.
- Загрузка из `localStorage`: функция `loadLeads()`.
- Сохранение в `localStorage`: функция `saveLeads()`.
- Создание объекта лида: функция `createLead()`.
- Отображение карточек: функция `renderLeads()`.
- Изменение этапа сделки: функция `updateLeadStage()`.
- Очистка формы: функция `resetForm()`.

Все данные хранятся под ключом `crm_leads`.

## Как работает приложение

1. При открытии страницы `loadLeads()` читает сохранённый массив из `localStorage`.
2. Пользователь заполняет форму и нажимает «Сохранить лид».
3. Обработчик отменяет стандартную отправку формы с помощью `preventDefault()`.
4. `validateForm()` проверяет имя и телефон после удаления лишних пробелов.
5. `createLead()` создаёт объект с уникальным `id` и временем создания.
6. Новый объект добавляется в массив, а `saveLeads()` сохраняет его в браузере.
7. `renderLeads()` заново отображает карточки через `document.createElement()` и `textContent`.
8. При смене этапа `updateLeadStage()` обновляет нужный объект по `id` и снова сохраняет массив.
